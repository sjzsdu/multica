# 市场进入作战手册（一人公司版）

## 适用场景

产品已具备可用版本，需要从"能做"走到"有人用、有人买"。用于制定定位、选择渠道、安排发布节奏与建立增长指标。

## 一、先定坐标，再谈动作

在任何渠道动作之前，先明确四件事，缺一项就不进入执行：

1. **目标客户（ICP）**：谁在什么场景下、因为什么触发事件，产生这个需求。用"角色 + 场景 + 触发条件"描述，不用人口统计学标签代替。
2. **替代方案**：客户现在怎么解决。包括竞品、Excel、人工、忍耐不做。你的真正对手通常是"维持现状"。
3. **价值主张**：客户获得的可验证结果，而不是功能列表。格式：帮助〔谁〕在〔场景〕下〔达成什么结果〕，不同于〔替代方案〕，因为〔证据〕。
4. **证据**：可展示的数据、案例、演示、第三方背书。没有证据的主张一律降级为假设。

## 二、渠道选择：先窄后宽

按三个维度给渠道打分（1-5），只选总分最高的一个作为主渠道：

| 维度 | 判断问题 |
| --- | --- |
| 客户密度 | 目标客户是否集中在这个渠道？ |
| 可复用性 | 一次投入能否持续带来流量，而不是一次性消耗？ |
| 边际成本 | 增加一次发布/触达，人力与现金成本是否接近零？ |

一人公司的默认顺序：能被搜索到的内容 → 目标客户聚集的社区 → 可复用的外联序列 → 付费投放。付费投放放在转化路径已被验证之后。

**硬规则**：主渠道未跑通"曝光 → 访问 → 激活 → 付费"完整闭环前，不新增第二个渠道。全渠道平均用力是最常见的失败方式。

## 三、发布节奏

一次发布按四段安排，每段都有明确产出：

1. **预热**：目标客户能感知的信号，提前积累关注与名单。
2. **发布**：主渠道集中投放，配套落地页、演示与说明。
3. **承接**：新访客的下一步路径（试用、预约、订阅），以及 48 小时内的响应机制。
4. **复盘**：渠道来源、转化率、放弃点、可复用素材。

发布不是一次性事件：把发布内容拆成可持续分发的素材，延长生命周期。

## 四、指标体系

建立一条最小漏斗，每层只保留一个主指标：

曝光 → 访问 → 激活（首次获得价值）→ 付费 → 留存/推荐

- 北极星指标必须与客户获得的价值直接相关，不能是注册数或页面浏览量。
- 每个动作在开始前声明预期影响哪一层、预期幅度、观察窗口。
- 区分领先指标（可快速反馈）与滞后指标（收入、留存）。
- 无数据时先做小样本验证，不凭直觉铺量。

## 五、一人公司约束

- 任何需要持续人工值守的渠道，默认不做，除非已验证 ROI。
- 内容与素材必须可复用：一份深度内容至少服务三个渠道。
- 自动化优先于人力扩张；外包只在流程稳定后考虑。
- 每个季度只允许一个"增长实验"占用主要精力。

## 六、交付物

一份可执行的市场计划至少包含：ICP 定义、价值主张与证据、主渠道与理由、30 天动作表（动作/负责人/验收标准/指标）、预算上限、止损条件。
